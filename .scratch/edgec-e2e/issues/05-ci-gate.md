# 05 门禁判定:报告 → 退出码

Status: resolved
Type: task
Blocked by: 04 测试报告:四档结论与两栏通过率

**What to build:** GitHub 的 job 结论只有红绿两态,而我们有四档结论。本票提供一个判定器:吃一批 `summary.json`,给出唯一的红绿答案与理由。纯函数,不起进程不连网络。

## 验收

- [x] 全合格 → 退出码 0
- [x] 任一**不合格** → 红,且理由里优先显示不合格
- [x] 任一**测试无效** → 红,理由写明"平台问题,不是产品"
- [x] 任一**未完成**(申报外未测)→ 红
- [x] 任一**平台错误**(产品起不来/任务配置错)→ 红,理由指向平台
- [x] 混档(既有不合格又有无效)→ 红,且两类都列出,不互相掩盖
- [x] **空输入(0 个任务)→ 红**,并说明"没有任何任务被跑过"(不能因为没跑就绿)
- [x] 每条规则有对应用例;把任一规则删掉,对应用例必须红
