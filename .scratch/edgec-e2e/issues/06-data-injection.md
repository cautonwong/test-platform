# 06 数据注入与模拟器能力声明

Status: resolved
Type: task
Blocked by: 01 一条任务跑起来(最小闭环)

**What to build:** 两件事,都是为了让"设备报 X,产品该做什么"可测、让 CI 知道某型号能不能跑。

1. **数据注入**:场景里中途改模拟设备的读数(如把电量设成 1234),产品下次读拿到新值;这个动作必须留痕。
2. **模拟器能力声明**:每个模拟器声明支持哪些故障注入(超时/坏 CRC/慢/断链),由此推导型号的 CI 可跑性。

## 验收

- [x] `inject(设备, 读数键, 值)` 生效:产品下一次读拿到新值
- [x] 注入写入证据(带用例身份),事后能看出"这个值是测试设的"
- [x] 注入点必须是该型号点表里已声明的量;拼错当场报错
- [x] **注入不得替代写路径**:测"产品能否写设备"必须走协议写;有用例或守卫证明注入不产生写入记录
- [x] 模拟器声明故障注入种类;声明未知种类 → 装配期报错
- [x] 报告/目录能显示某型号的 CI 可跑性与可注入故障
- [x] 把某个模拟器的能力声明删掉,对应用例必须红
- [x] 基线不回归
