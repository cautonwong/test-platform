## 6. 三个符号值要一句话确认(不是数字,是代号)

条款里的额定值写成了代号。同一个代号在不同被试品上是不同的数,所以只能由你们给一句话:

| 写法 | 出现次数 | 出现在哪里 | 我们缺的那句话 |
|---|---|---|---|
| Ua=Un / Ub=Un / Uc=Un | 120 / 120 / 120 | 105 条条款每一条的第 1 步(例:第 8 行) | 这批表的额定电压是单相 220V,还是三相 220/380V? |
| Fre=Hz | 138 | 105 条条款每一条的第 1 步(例:第 8 行) | 额定频率 50Hz 还是 60Hz? |
| Ia=Ib / Ib=Ib / Ic=Ib | 25 / 24 / 24 | 例:第 3533、3627、3689、3753、3872 行 | 这里的 Ib 指额定(基本)电流吗? |
| Ua=Ux+5V | 1 | 第 4154 行 步骤5「表计只加单相电压」 | Ux 指什么?(欠压/额定值/前一步的读数) |

我们不填默认值:电压或频率猜错,台架会按错的额定值跑,测试全绿而结论是错的 ——
这种错在报表里看不出来。

要我们拿到什么:上表每一行一句话。如果统一口径就是「按型号铭牌」,那请给型号清单
(型号 → 额定电压 / 额定频率 / 额定电流)。
